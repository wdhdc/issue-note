Issue Notes

把 GitHub Issues 变成你的个人笔记

Issue Notes 是一个纯前端界面，把你的 GitHub 仓库 Issues 当作 Markdown 笔记来使用。无需安装、无需服务器，数据始终保存在你自己的仓库里。

  • Markdown 原生标题、列表、引用、代码块、表格、任务清单，GFM 格式完整支持。
  • 实时预览边写边看效果，常用格式一键插入。
  • 标签分类用 Issues 的 labels 给笔记打标签，按标签筛选。
  • 全文搜索基于 GitHub 搜索，快速定位标题或正文中的关键词。
  • 私有仓库支持通过 Fine-grained PAT 安全地读写你私有仓库里的笔记。
  • 扩展语法Alert 提示框、脚注、数学公式、Mermaid 图表。
1. 选择仓库
2. 验证访问
3. 进入笔记
